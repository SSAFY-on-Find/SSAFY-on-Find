# MongoDB vs RDBMS

## ✅ 주제

MongoDB와 RDBMS의 구조적 차이 및 사용 목적 비교

---

## 🧩 1. 정의

| 항목    | MongoDB                       | RDBMS (Relational DBMS)             |
| ----- | ----------------------------- | ----------------------------------- |
| 정의    | 문서(Document) 기반의 NoSQL 데이터베이스 | 테이블 기반의 전통적인 관계형 데이터베이스             |
| 대표 제품 | MongoDB                       | MySQL, PostgreSQL, Oracle, MS SQL 등 |

---

## 🏗️ 2. 데이터 구조

| 항목     | MongoDB                        | RDBMS                |
| ------ | ------------------------------ | -------------------- |
| 저장 단위  | 컬렉션(Collection) & 문서(Document) | 테이블(Table) & 행(Row)  |
| 데이터 포맷 | JSON, BSON (유연한 구조)            | 스키마 기반 정형 데이터        |
| 스키마    | 유연함 (동적 스키마)                   | 엄격함 (정적 스키마)         |
| 관계     | 비관계형 (중첩된 데이터 구조)              | 관계형 (JOIN을 통한 관계 설정) |

---

## ⚙️ 3. 특징 비교

| 항목    | MongoDB                | RDBMS             |
| ----- | ---------------------- | ----------------- |
| 확장성   | 수평적 확장 (Sharding 등)    | 수직적 확장 위주         |
| 트랜잭션  | 제한적 트랜잭션 (최근에는 지원 강화됨) | 강력한 ACID 트랜잭션 지원  |
| 성능    | 대용량 비정형 데이터에 강점        | 정형 데이터 처리에 효율적    |
| 사용 사례 | 로그, IoT, 사용자 이벤트 등     | 금융, 회계, ERP 시스템 등 |

---

## 💡 요약

* **MongoDB**는 유연한 구조와 빠른 개발 속도를 원하는 경우에 적합한 **NoSQL** 데이터베이스입니다.
* **RDBMS**는 정형화된 데이터와 트랜잭션 무결성이 중요한 시스템에 적합합니다.
* 두 시스템은 상호 대체재가 아닌, 목적과 데이터 성격에 따라 **보완적으로 사용**되기도 합니다.
